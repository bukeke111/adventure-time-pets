# 精灵图布局

当前 Codex 宠物格式使用 8 列 × 9 行的精灵图。

| 项目 | 数值 |
| --- | --- |
| 完整尺寸 | 1536 × 1872 px |
| 单元格尺寸 | 192 × 208 px |
| 列数 | 8 |
| 行数 | 9 |
| 背景 | 透明背景或由运行时移除的色键背景 |

每个单元格从左到右、从上到下编号。未使用的单元格应保持为空。实际角色精灵图属于同人素材，不随公开仓库提供。

## 加载单元格

给定列 `column` 和行 `row`，单元格左上角坐标为：

```text
x = column * 192
y = row * 208
```

CSS 和 Canvas 示例使用相同的坐标约定。
